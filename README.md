# plamo-toolbox
A portable toolbox for plastic model building tools
<img width="1917" height="1078" alt="Screenshot 2026-10-17 231855" src="https://github.com/user-attachments/assets/54257816-1dd0-4bbc-8850-89f212ea8531" />

Features:
Clamshell lid with 2 locking latches
2 stacked storage trays for tools
- First tray has dedicated compartments for sanding and polishing tools, as well as a hobby knife handle.
- Second tray has storage for other items, notably solvent cement bottle holders.
